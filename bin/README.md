# Bin Directory

Command-line utilities for the metal project.

## Scripts

- **metal** - Main CLI tool
- **benchmark** - Performance benchmark runner

## Usage

```bash
# Main CLI
./bin/metal build
./bin/metal test
./bin/metal demo
./bin/metal validate
./bin/metal e2e
./bin/metal package
./bin/metal explore

# Quick benchmark
./bin/benchmark
```

## Installation

Add to PATH for global access:
```bash
export PATH="$PWD/bin:$PATH"
metal help
```

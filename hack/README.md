# Hack Directory

Quick utilities and experimental components for the metal project.

## Scripts

- **profiler.swift** - Performance profiling utility
- **kernel_config.swift** - Metal kernel configuration generator
- **validate_metal.swift** - Metal shader validation script

## Usage

```bash
# Run profiler
swift hack/profiler.swift

# Generate kernel configs
swift hack/kernel_config.swift

# Validate Metal shaders
swift hack/validate_metal.swift
```
